# 岩井製菓シフト管理システム 開発進捗報告書 ver.5

## 1. システム概要

### 1.1 プロジェクト目的
岩井製菓の店舗運営における人員配置の最適化と、シフト作成業務の効率化を図るためのWindowsデスクトップアプリケーションを開発。従業員が簡単にシフト希望を提出でき、管理者がそれを考慮したシフト作成を行えるようにし、勤怠管理機能も統合した一元的な労務管理システムを構築。

### 1.2 技術スタック
- **フロントエンド**: React + TypeScript
- **デスクトップ実行環境**: Electron
- **認証**: Firebase Authentication
- **データベース**: Firestore
- **状態管理**: React Context API
- **UI**: Material-UI v7
- **AI機能**: OpenAI API (GPT-4o)

### 1.3 主要機能
#### 管理者機能
- **ダッシュボード**: 季節情報、イベント情報、機能アイコン
- **シフト管理**: カレンダー表示、編集、AIによる自動生成、希望・勤怠状況確認
- **従業員管理**: 情報登録・編集・削除、スキル設定
- **店舗管理**: 店舗情報、必要スキル設定
- **イベント・季節情報管理**: 季節の開花状況、イベント管理
- **AIアシスタント**: OpenAI APIによる対話型サポート

#### 従業員機能
- **プロフィール管理**: 個人情報編集
- **シフト希望入力**: 月単位の希望提出
- **勤怠管理**: 出退勤・休憩打刻、勤務履歴
